# Licence

Two different things are licensed here, and conflating them would tell you that
you have rights you do not have.

## The code: CC0 1.0 (public domain)

Everything in this package that was written for it. Use it, fork it, sell it,
no attribution required.

## The data: not CC0, and not ours to relicense

The server returns values fetched from UK public sources. Those come with their
publishers' conditions attached, and they travel with the data whatever this
package's own licence says:

| Source | Terms |
| --- | --- |
| Most sources (ONS, Home Office/police, HM Land Registry, Defra, Environment Agency, DfE, MHCLG) | Open Government Licence v3.0. Commercial use permitted **with attribution**. |
| Postcode geography (ONSPD, via postcodes.io) | OGL v3, but contains OS and Royal Mail derived intellectual property with permitted-use conditions. |
| Ofcom Connected Nations (broadband, mobile) | Ofcom's own terms, not OGL. |
| OpenStreetMap, via Overpass (amenities, transport) | Open Database Licence (ODbL) 1.0. Share-alike attaches to a derived database; a report is a "produced work" and is treated more permissively. |
| TfL (London transport) | TfL open data licence. |

Every tool response carries the required attribution string. **Please keep it
attached.** If you strip it, you are the one out of compliance, not us.

## If you intend to sell something built on this

The code licence does not clear the data. In particular, commercial
redistribution under the Ofcom terms, and commercial use of postcode geography
under the OS and Royal Mail conditions, are open questions that have not been
answered for this project. `COMMERCIAL.md` records them. They are questions for
a solicitor, not for a README.

Full OGL text: https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/
